# 0008 Licence

**Status:** decided (David, 2026-11-24): "as open as it gets".

| Part of the repository | Licence |
|---|---|
| `hardware/`, `mechanical/` (schematics, boards, libraries, models, exports) | CERN-OHL-S-2.0 |
| Everything else, and the generator scripts | AGPL-3.0 |

AGPL-3.0 was David's original choice for everything. It is written for software; CERN-OHL-S-2.0 is the strong
copyleft licence written for hardware, so it was added for the design files. Both require anyone distributing a
modified design, or a product made from it, to publish their source under the same terms.
