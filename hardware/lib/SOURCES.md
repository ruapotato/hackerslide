# Sources and licences for `hardware/lib`

Everything in this directory is **generated by [`hardware/scripts/mklib.py`](../scripts/mklib.py)** and
licensed CERN-OHL-S-2.0 with the rest of the hardware. No vendor CAD file is copied. Each item was drawn from
dimensions in a public document, listed below. Dimensions and pin tables are facts taken from those documents;
the documents themselves are not redistributed here.

## Footprints (`hackerslide.pretty`)

| Footprint | Drawn from | Checked |
|---|---|---|
| `Hirose_DF40C-100DS-0.4V_2x50_P0.4mm` | Hirose DF40 catalogue p.3, recommended PCB layout (pad 0.2 x 0.70, rows 3.08 apart, span 19.6). Cross-checked against the geometry of the Raspberry Pi CM4IO KiCad footprint (not copied) | Audit, 2026-11-24: matches both |
| `Hirose_FH34SRJ-20S...` and `-8S...` | Hirose FH34 catalogue p.5, "Recommended PCB mounting pattern" for FH34SRJ | Read off the drawing by one person; **needs a second check** |
| `FPC_Fingers_1x08_P0.5mm_FH34` | Hirose FH34 catalogue p.5, "Recommended FPC/FFC dimensions"; JLCPCB flex capabilities (finger to edge 0.2 mm) | Needs a second check |
| `Jack_3.5mm_SHOUHAN_PJ-342` | SHOU HAN PJ-342 drawing (LCSC C668606), PCB terminal view | Land positions read off the drawing; pole assignment inferred. **Check with a sample** |
| `SW_Alps_SKSWCFE010_3x2mm` | Alps SKSW drawing (LCSC C255576 datasheet p.2) | Audit: matches. The current Alps catalogue gives 2.7 mm inner gap against 2.6 here |
| `SW_Keystone_5135_Dome_7mm` | Keystone catalogue p.97 for the dome; **the lands are NOT Keystone's** (theirs do not fit the key pitch) | Not verified. Get Keystone's Mini-series land drawing |
| `MountingHole_M2.5_CM4_Standoff` | 2.7 mm drill as on the CM4IO board | Unused since the carrier moved to SMT spacers; kept for reference |
| `MountingHole_M1.6_NPTH`, `MountingHole_M1.6_Pad`, `MountingHole_M2_NPTH_BodyScrew`, `ContactPad_2x4mm` | Plain shapes, no source | - |

## From KiCad's own libraries

All other symbols and footprints come from the KiCad 9 libraries (CC-BY-SA 4.0 with the KiCad library
exception, which allows use in designs without imposing that licence on them). The generated schematics embed
copies of the symbols they use, as KiCad always does.
